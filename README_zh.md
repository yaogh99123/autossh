# AutoSSH (Timo Edition)

一个强大的交互式 SSH 远程客户端，专为 macOS/Linux 终端打造。它不仅能帮助您保存复杂的 SSH 密码和密钥路径，还集成了极其高效的模糊搜索与文件传输功能。

本项目基于 [Lenbo/autossh](https://github.com/islenbo/autossh) 进行二次开发与增强。

![演示](https://raw.githubusercontent.com/yaogh99123/autossh/main/docs/images/ezgif-5-42b5117192fc.gif)

## 核心增强功能 (vs 原版)

- **源码级 FZF 集成**：内置了官方 `fzf` 模糊搜索引擎，**无需安装外部 fzf 二进制文件**。支持非全屏弹出（40% 高度），在搜索时保留上下文视野。
- **YAML 配置支持**：全面支持 `config.yml` 格式，配置更清晰，读写更健壮。
- **智能 SSH 密钥关联**：在添加服务器时，自动扫描 `~/.ssh` 目录并提供模糊选择界面，一键绑定私钥，告别手动输入长路径。
- **高性能并行传输**：
  - 交互模式支持 `up`/`down` 指令。
  - 支持 `-j` 参数指定多线程并发数，大幅提升大批量小文件传输速度。
  - 完美支持 `-r` 文件夹递归传输。
- **UI 交互优化**：
  - **列表折叠**：默认仅显示前 8 个服务器，支持 `a` (全部) / `h` (隐藏) 指令，保持界面清爽。
  - **序号检索**：搜索框支持直接输入列表序号（如 `a1`, `b2`）精准定位。
  - **信号保护**：增强了 `Ctrl+C` 全局捕获，确保任何状态下都能优雅退出。

## 🛠 功能说明

### 1. SSH 快速登录

- 运行 `./autossh` 进入交互界面。
- 输入 **序号** (如 `1` 或 `a1`) 或 **别名** 直接登录。
- 输入 **`s`** 开启模糊搜索模式。

### 2. 文件上传与下载 (基于 SFTP)

支持在主界面直接输入指令进行传输：

- **上传**：`up [-r] [-j 10] <本地路径> <服务器名/序号:远程路径>`
- **下载**：`down [-r] [-j 10] <服务器名/序号:远程路径> <本地路径>`
- **示例**：`up -r -j 10 ./dist server1:/var/www/html`

### 3. 管理服务器

- **添加**：输入 `add`。
- **编辑**：输入 `edit`。
- **删除**：输入 `remove`。

### 4. 自动更新

- 输入 `upgrade` 自动检测并升级到 `yaogh99123/autossh` 的最新版本。

## 📦 安装与编译

### 直接运行

Mac/Linux 用户下载 Release 包后，运行 `install` 脚本即可。

### 手动编译

本项目使用 `vendor` 模式管理依赖，确保源码级构建：

```bash
# 生成所有平台的二进制包
./build.sh

# 仅编译当前平台
make build
```
